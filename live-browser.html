Live Amazon Browser

This Chrome window is driven by the Amazon Review Checker, so that staff can watch each check. Amazon pages open in the next tab, one at a time, at least 3 seconds apart.

It never types into Amazon, never reads or keeps a password, and never gets around a login page, a robot check or a block. When Amazon stops a step, the check says so and the user goes to a manual staff check.

This window keeps its own Chrome profile. Log in to Amazon here by hand, and tick the box that keeps you signed in, so you stay logged in after a restart. Keep it open: every check uses it.
